# 한국사 기본 기출 랜덤 퀴즈

한국사능력검정시험 **기본** 기출문제(60·61·63·64·66·67·69·71·73·75회, 500문항) 학습용 웹앱.

- **시대별 멀티셀렉트** → 무작위 출제
- 즉시 채점 + 해설 (시대 태그 · 핵심 주제)
- **오답노트**: 틀린 문제 자동 저장, 다시 풀기, 맞히면 자동 제거
- **학습 기록**: 세션별 성적 이력, 시대별 누적 정답률
- 데이터는 브라우저 localStorage에 저장 (기기별)

## 출처

- 기출문제·정답: [국사편찬위원회 한국사능력검정시험](https://www.historyexam.go.kr/) — 비상업적 개인 학습 용도
- 해설: 자동 생성된 참고용 자료로, 오류가 있을 수 있습니다.
