# 한국사 기본 기출 랜덤 퀴즈

한국사능력검정시험 **기본** 기출문제(60·61·63·64·66·67·69·71·73·75회, 500문항) 학습용 웹앱.

## 기능

- 상단 탭 3개(문제 풀이 / 복습 / 학습 기록)로 화면 분리. 세 탭이 같은 머리글·같은 탭 줄을 써서
  탭을 옮겨도 탭 위치가 움직이지 않는다
- **시대·회차 멀티셀렉트 + 문항 번호 범위(k~n)** → 무작위 출제
- 즉시 채점 + 해설 (시대 태그 · 핵심 주제)
- **최근 출제 회피** — 문항마다 몇 번째 세션에 풀었는지를 기록해, 뽑을 때 오래전에 푼 문항·아직 안
  풀어본 문항을 먼저 쓴다(LRU). 500문항을 20문항씩 풀면 **25회까지 중복 없이** 돌고, 풀이 모자라면
  막히지 않고 가장 오래전에 푼 문항부터 재사용한다.
  **출제됐지만 답하지 않고 넘긴 문항은 안 본 것으로 처리**해 다시 나온다
- **복습 탭** — 오답노트와 별표를 분리해 보관, 각각 시대 필터와 '필터 결과만 다시 풀기' 지원
  - **오답노트**: 틀리면 자동 저장, 다시 풀어 맞히면 자동 제거(설정)
  - **★ 별표**: 잘 몰라서 찍은 문항을 정답·오답과 무관하게 표시 — **보기(①②③④) 왼쪽 ☆ 버튼**으로 토글해
    답을 고르는 손 위치에서 바로 누를 수 있다. 해설 화면에서도 표시 가능, 별표만 모아 다시 풀기
- **중간 저장 & 정지** — 문제 풀기 / 오답 복습 / 별표 복습을 각각 별도 슬롯에 보관하고 홈에서 '이어서 풀기'
- **학습 기록** — 세션 이력, 시대별 누적 정답률, '풀어본 범위' 진행률
- **버전 자동 갱신** — `version.json`을 확인해 새 버전이면 설정·중간저장만 비우고 최신 UI로 자동 새로고침
  (오답노트·별표·학습기록·풀어본 범위는 보존)
- 데이터는 브라우저 localStorage에 저장 (기기별, 키 접두어 `khq_`)

문항이 이미지라 보기 순서 무작위(간호조무사 앱의 기능)는 적용할 수 없다.

## 색 사용 규칙

화면마다 다른 색을 쓰지 않고 역할로 고정한다. 색을 추가할 때는 `:root` 토큰으로만 넣는다.

| 토큰 | 역할 |
|---|---|
| `--acc` (밝은 파랑) | 실행·긍정 — 주 버튼, 선택한 칩, 정답, 해설 |
| `--acc2` (남색) | 구조·이동 — 활성 탭, 소제목, 표 머리, 세그먼트 |
| `--star` (금색) | 별표 전용 |
| `--ok` / `--warn` / `--bad` | 성취도 |

## 배포 시 주의

기능·UI를 바꾸면 `index.html`의 `APP_VERSION`과 `version.json`의 `app`을 **같은 값으로** 올린다.
문항을 바꾸면 `version.json`의 `data`도 함께 올린다.

푸시는 두 브랜치에 함께: `git push origin main main:gh-pages`
